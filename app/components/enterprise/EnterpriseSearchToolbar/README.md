# Enterprise Search Toolbar

Reusable search and control system for the EPEW Enterprise Admin Design System.

## Features

- Debounced search
- Keyboard shortcut support
- Multiple filters
- Sorting controls
- Table, grid, list, and compact views
- Permission-aware action buttons
- Loading states
- Disabled states
- Active-filter tracking
- Clear-all-filters control
- Responsive enterprise layout
