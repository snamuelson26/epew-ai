FORM AND PROCESSING
- SMS and email subscriptions are separate and optional; both checkboxes start unchecked. Selecting Text Message alone does not subscribe the person.
- Verified EPEW sign-in and same-origin writes protect preference capture. Server verifies the actor; entering someone else's email cannot overwrite their record.
- Saving without either subscription is allowed by the handler and database. SMS consent is not required to continue an application.
- Server saves normalized phone, SMS grant/decline, timestamp, source URL, disclosure version, full text and disclosure language. Preferred communication language is recorded separately; this disclosure version is English.
- Legacy combined communications consent never grants SMS. All eight prior contacts remained SMS=false; no historical consent was converted.
- Application SMS requires current explicit evidence and a send-time suppression check. Old queued messages are rechecked. Supporter SMS fallback is removed because this disclosure excludes marketing and donation requests.
- STOP suppression persists across preference saves. START does not manufacture consent or erase suppression.
- New /api/twilio/sms validates Twilio signatures, stores STOP before confirmation and provides HELP without duplicate provider-handled replies. This is a Twilio endpoint, NOT a Sent webhook. Do not point Sent at a Twilio signature-specific endpoint.
