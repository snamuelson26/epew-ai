EPEW scheduled appointment integration — paused release

This release adds a Sent branch to the existing appointment worker. Production provider selection and live flags are not changed. Existing Twilio sending remains the default. Selecting EPEW_APPOINTMENT_MESSAGE_PROVIDER=sent without EPEW_SENT_APPOINTMENT_LIVE_ENABLED=true returns paused before preparing or claiming queue rows. Do not set live enablement before controlled, charge-authorized launch tests and approval prerequisites.

Sent requires current channel eligibility from the appointment recipient view and no historical opt-out on either channel. SMS additionally rechecks explicit current SMS consent and EPEW_SENT_SMS_APPROVED=true. WhatsApp permission is independent; SMS consent is never converted. Templates come from private configuration sent:template:en / fr / ht / es with value {id:approvedTemplateId}; no mappings are installed by this release. Missing language templates block sends rather than silently choosing an English template.

Delivery rows gain provider (default twilio) and sent_event_updated_at. A reservation refuses previously attempted Twilio rows or rows already bound to another message, preventing blind provider cutover. Sent-reserved rows never fall back to Twilio after a configuration change. The provider message ID binds durably before completion and replays earlier signed events from the private ledger. Later events project by their provider timestamp; read/delivered evidence cannot regress. Before-routing auto/sent/null channels are supported for status events on an explicitly pinned send. Filtered/blocked states do not retry; route failures become unknown for reconciliation. Twilio callbacks reject Sent-owned delivery rows.

Post-submission timeout, 5xx, 409, malformed acceptance, unknown failure or binding failure enters an unknown/manual-reconciliation state rather than automatic resend. 429 respects Retry-After with a minimum five-minute backoff; terminal 4xx is not automatically retried. The transport uses the same delivery logical ID/idempotency key.
